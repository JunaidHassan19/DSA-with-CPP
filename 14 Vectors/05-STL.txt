========================================================
  STL — Standard Template Library in C++
========================================================

What is STL?
-------------
STL stands for Standard Template Library.
It is a collection of pre-built classes and functions in C++
that provide ready-made implementations of common data
structures and algorithms.

In simple words:
  Instead of writing everything from scratch, C++ gives us
  a library of powerful tools we can directly use.


Why is it called "Template" Library?
--------------------------------------
Because STL uses C++ Templates (generics), which means the
same data structure can work with any data type.

  vector<int>     → vector of integers
  vector<string>  → vector of strings
  vector<float>   → vector of floats

One code, multiple types — that's the power of templates.


4 Main Components of STL:
---------------------------

  1. CONTAINERS  — Data structures that store data.
  2. ALGORITHMS  — Functions that operate on containers (sort, search, etc.)
  3. ITERATORS   — Objects used to traverse/access container elements.
  4. FUNCTORS    — Objects that act like functions (advanced topic).


1. CONTAINERS (Data Structures)
---------------------------------
Containers store collections of data. Major types:

  a) Sequence Containers (ordered by insertion):
     - vector       → dynamic array (most commonly used)
     - list         → doubly linked list
     - deque        → double-ended queue
     - array        → fixed-size array (C++11)

  b) Associative Containers (sorted by key):
     - set          → unique sorted elements
     - map          → key-value pairs (sorted by key)
     - multiset     → allows duplicate sorted elements
     - multimap     → allows duplicate keys

  c) Unordered Containers (hash-based, no order):
     - unordered_set
     - unordered_map
     - unordered_multiset
     - unordered_multimap

  d) Container Adapters (built on top of other containers):
     - stack        → LIFO (Last In First Out)
     - queue        → FIFO (First In First Out)
     - priority_queue → element with highest priority comes first


2. ALGORITHMS
--------------
STL provides many built-in algorithms in <algorithm> header.

  Common ones:
    sort(begin, end)         → sorts a range
    reverse(begin, end)      → reverses a range
    find(begin, end, value)  → finds an element
    count(begin, end, value) → counts occurrences
    min_element(begin, end)  → returns iterator to smallest
    max_element(begin, end)  → returns iterator to largest
    binary_search(begin, end, value) → true/false
    swap(a, b)               → swaps two values

  Example:
    vector<int> v = {5, 2, 8, 1, 9};
    sort(v.begin(), v.end());        // v → {1, 2, 5, 8, 9}
    reverse(v.begin(), v.end());     // v → {9, 8, 5, 2, 1}


3. ITERATORS
-------------
Iterators are like pointers that help us traverse containers.

  vector<int> v = {10, 20, 30};

  vector<int>::iterator it;
  for (it = v.begin(); it != v.end(); it++) {
      cout << *it << " ";   // 10 20 30
  }

  Shortcut (auto keyword):
  for (auto it = v.begin(); it != v.end(); it++) {
      cout << *it << " ";
  }

  Even shorter (range-based for loop):
  for (int val : v) {
      cout << val << " ";
  }

  Key iterator functions:
    v.begin()  → iterator to first element
    v.end()    → iterator to one past the last element
    v.rbegin() → reverse iterator to last element
    v.rend()   → reverse iterator to one before first


4. FUNCTORS (Function Objects)
-------------------------------
A functor is an object that behaves like a function.
It's a class/struct that overloads the () operator.

  struct Multiply {
      int operator()(int a, int b) {
          return a * b;
      }
  };

  Multiply mul;
  cout << mul(3, 4);   // Output: 12

  (Advanced topic — will cover later)


Why use STL?
-------------
  - No need to reinvent the wheel.
  - Well-tested and optimized code.
  - Works with any data type (templates).
  - Makes coding faster, especially in competitions.
  - Reduces bugs — less manual memory management.


Most Important for Now: VECTOR
--------------------------------
Vector is the most commonly used STL container.
It is a dynamic array that can grow and shrink automatically.
No need for new/delete — vector handles memory for us!

  #include <vector>

  vector<int> v;          // empty vector
  v.push_back(10);        // adds 10 at the end
  v.push_back(20);        // adds 20 at the end
  v.size();               // returns 2
  v[0];                   // access first element → 10
  v.pop_back();           // removes last element

(We'll explore vectors in detail in the next files.)


Summary:
---------
  - STL = Standard Template Library (pre-built tools in C++).
  - 4 components: Containers, Algorithms, Iterators, Functors.
  - Containers = data structures (vector, set, map, stack, queue...).
  - Algorithms = sort, reverse, find, count, etc.
  - Iterators = pointers to traverse containers.
  - Vector is the most important container to learn first.
