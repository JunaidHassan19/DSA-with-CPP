INTRODUCTION TO GRAPHS
======================

What is a graph?
----------------
A graph is a data structure made of two things: nodes (also called vertices) and
edges (connections between nodes). Everything else is a variation on that core idea.


THE THREE MAIN TYPES
--------------------

Undirected graph
  Edges have no direction. If A connects to B, B also connects to A.
  Example: Facebook friendships.

Directed graph (digraph)
  Edges are one-way arrows. A can point to B without B pointing back.
  Example: Twitter follows, or a dependency chain.

Weighted graph
  Each edge has a numeric value (cost, distance, time).
  Example: A map where edges represent road distances between cities.


KEY TERMS
---------
Node (vertex)   - An entity in the graph
Edge            - A connection between two nodes
Directed edge   - Has a specific direction (one-way)
Weighted edge   - Has a numeric cost or distance
Degree          - Number of edges on a node
                  (In directed graphs: in-degree and out-degree separately)
Path            - A sequence of nodes walked along connected edges
Cycle           - A path that starts and ends at the same node
Connected       - Every node can reach every other node (undirected graphs)
Sparse vs dense - Few edges vs many edges relative to number of nodes


HOW GRAPHS ARE STORED IN CODE
------------------------------

Adjacency List
  Each node stores a list of its neighbors. Efficient for sparse graphs.

  graph = {
      'A': ['B', 'C'],
      'B': ['A', 'D'],
      'C': ['A'],
      'D': ['B']
  }

Adjacency Matrix
  A 2D grid where matrix[i][j] = 1 means an edge exists.
  Fast lookups, but uses O(n^2) space.
