===============================================
         DATA TYPE MODIFIERS IN C++
===============================================

What are Data Type Modifiers?
------------------------------
Data type modifiers are keywords that change the properties of basic data types.
They modify the SIZE and RANGE of values a data type can hold.


Types of Data Type Modifiers
-----------------------------
There are 4 modifiers in C++:

1. signed    - Can store both positive and negative numbers (default)
2. unsigned  - Can store only positive numbers (0 and above)
3. short     - Reduces the size (uses less memory)
4. long      - Increases the size (uses more memory)


How Modifiers Work with int
----------------------------

┌─────────────────────┬──────────┬─────────────────────────────────────┐
│     Data Type       │   Size   │              Range                  │
├─────────────────────┼──────────┼─────────────────────────────────────┤
│ short int           │ 2 bytes  │ -32,768 to 32,767                   │
│ unsigned short int  │ 2 bytes  │ 0 to 65,535                         │
│ int                 │ 4 bytes  │ -2,147,483,648 to 2,147,483,647     │
│ unsigned int        │ 4 bytes  │ 0 to 4,294,967,295                  │
│ long int            │ 4 bytes  │ -2,147,483,648 to 2,147,483,647     │
│ long long int       │ 8 bytes  │ -9.2×10¹⁸ to 9.2×10¹⁸               │
│ unsigned long long  │ 8 bytes  │ 0 to 18.4×10¹⁸                      │
└─────────────────────┴──────────┴─────────────────────────────────────┘


Understanding signed vs unsigned
---------------------------------

signed (default):
    - Uses 1 bit for sign (+ or -)
    - Remaining bits for value
    - Can store negative numbers
    
    Example: signed int (4 bytes = 32 bits)
    - 1 bit for sign
    - 31 bits for value
    - Range: -2³¹ to 2³¹-1 = -2,147,483,648 to 2,147,483,647

unsigned:
    - All bits used for value
    - No negative numbers
    - Double the positive range
    
    Example: unsigned int (4 bytes = 32 bits)
    - 0 bits for sign
    - 32 bits for value
    - Range: 0 to 2³²-1 = 0 to 4,294,967,295


MSB and LSB (Most & Least Significant Bit)
-------------------------------------------

What is MSB (Most Significant Bit)?
    - The LEFTMOST bit in a binary number
    - It has the HIGHEST value (highest power of 2)
    - In signed numbers, MSB represents the SIGN
        → MSB = 0 means POSITIVE number
        → MSB = 1 means NEGATIVE number

What is LSB (Least Significant Bit)?
    - The RIGHTMOST bit in a binary number
    - It has the LOWEST value (2⁰ = 1)
    - Determines if number is ODD or EVEN
        → LSB = 0 means EVEN number
        → LSB = 1 means ODD number


Visual Representation (8-bit example):
    
    Binary Number:  1  0  1  1  0  1  0  1
                    ↑                    ↑
                   MSB                  LSB
                (bit 7)              (bit 0)
              Highest value       Lowest value
                 (128)               (1)


Example 1: Number 13 in binary (8 bits)
    
        0    0    0    0    1    1    0    1
        ↑                                  ↑
       MSB                                LSB
       (0)                                (1)
    
    MSB = 0 → Positive number
    LSB = 1 → Odd number (13 is odd ✓)


Example 2: Number -5 in binary (8 bits, two's complement)
    
        1    1    1    1    1    0    1    1
        ↑                                  ↑
       MSB                                LSB
       (1)                                (1)
    
    MSB = 1 → Negative number
    LSB = 1 → Odd number (5 is odd ✓)


Example 3: Number 24 in binary (8 bits)
    
        0    0    0    1    1    0    0    0
        ↑                                  ↑
       MSB                                LSB
       (0)                                (0)
    
    MSB = 0 → Positive number
    LSB = 0 → Even number (24 is even ✓)


Why MSB is Important?
----------------------
1. In signed data types, MSB determines if number is positive or negative
2. Helps understand overflow conditions
3. Important in bitwise operations
4. Used in network protocols (Big Endian vs Little Endian)


Quick Trick to Check Even/Odd:
-------------------------------
Just look at the LSB!
    - If LSB = 0 → Number is EVEN
    - If LSB = 1 → Number is ODD

This is because:
    - All powers of 2 except 2⁰ are even
    - Only LSB (2⁰ = 1) can make a number odd

How Modifiers Work with double
-------------------------------

┌─────────────────────┬──────────┬─────────────────────┐
│     Data Type       │   Size   │    Precision        │
├─────────────────────┼──────────┼─────────────────────┤
│ float               │ 4 bytes  │ ~7 decimal digits   │
│ double              │ 8 bytes  │ ~15 decimal digits  │
│ long double         │ 12 bytes │ ~19 decimal digits  │
└─────────────────────┴──────────┴─────────────────────┘

Note: unsigned cannot be used with float/double


Practical Examples
-------------------

Example 1: When to use unsigned?
    - Age (can't be negative)
    - Count of items
    - Array index
    - Size of something

Example 2: When to use long long?
    - Very large numbers (like population of world)
    - Factorial of large numbers
    - Problems involving 10⁹ or larger values

Example 3: When to use short?
    - When memory is limited
    - When values are small (less than 32,767)
    - Embedded systems


Range Formula
--------------

For n bits:
    signed:    -2^(n-1)  to  2^(n-1) - 1
    unsigned:      0     to  2^n - 1

Examples:
    8 bits signed:   -2⁷ to 2⁷-1   =  -128 to 127
    8 bits unsigned:  0  to 2⁸-1   =  0 to 255
    
    16 bits signed:  -2¹⁵ to 2¹⁵-1 =  -32,768 to 32,767
    16 bits unsigned: 0   to 2¹⁶-1 =  0 to 65,535
    
    32 bits signed:  -2³¹ to 2³¹-1 =  -2.1 billion to 2.1 billion
    32 bits unsigned: 0   to 2³²-1 =  0 to 4.2 billion


Key Points to Remember
-----------------------
1. signed is the default modifier (no need to write explicitly)
2. unsigned doubles the positive range but removes negatives
3. short reduces memory, long increases memory
4. long long is for very large numbers (8 bytes)
5. unsigned cannot be used with float or double
6. Use sizeof() operator to check actual size on your system
7. Size may vary on different systems (32-bit vs 64-bit)
