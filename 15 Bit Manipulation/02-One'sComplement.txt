Bitwise Operator - One's Complement (~)
=========================================

The One's Complement operator (~) is a unary bitwise operator in C++.
It flips every bit of a number — 0 becomes 1 and 1 becomes 0.

Syntax:
-------
  ~operand

Example:
--------
  int a = 5;
  int result = ~a;

Step-by-step:
  a      =  0000 0101   (5 in binary, 8-bit representation)
  ~a     =  1111 1010   (every bit is flipped)

Result in decimal: -6


Why is ~5 equal to -6?
-----------------------
In C++, integers are stored using 2's complement representation.

For a 32-bit int:
  5  =  00000000 00000000 00000000 00000101
  ~5 =  11111111 11111111 11111111 11111010

The result (11111111...11111010) is the 2's complement representation of -6.

Formula:
  ~n = -(n + 1)

Examples:
  ~0  = -(0 + 1)  = -1
  ~1  = -(1 + 1)  = -2
  ~5  = -(5 + 1)  = -6
  ~10 = -(10 + 1) = -11
  ~(-1) = -(-1 + 1) = 0
  ~(-6) = -(-6 + 1) = 5


One's Complement vs Two's Complement:
--------------------------------------
- One's Complement: Simply flip all bits.
    One's complement of 5 (0000 0101) → 1111 1010

- Two's Complement: Flip all bits and add 1.
    Two's complement of 5 → 1111 1010 + 1 = 1111 1011
    This is how negative numbers are stored in memory.

Relationship:
  Two's Complement = One's Complement + 1
  i.e., -n = ~n + 1


Key Points:
-----------
1. ~ is a unary operator (works on a single operand).
2. It flips every bit (0 → 1, 1 → 0).
3. ~n always equals -(n + 1) for signed integers.
4. Works on int, char, short, long, etc.
5. The result depends on the size of the data type (8-bit, 16-bit, 32-bit, etc.).
