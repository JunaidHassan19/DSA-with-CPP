========================================================
  OOPs Intro for C++ Strings (std::string)
========================================================

Why do we need OOPs here?
--------------------------
So far we have been using char arrays (C-style strings) to work with text.
But char arrays have many limitations:
  - We need to manage size manually.
  - No built-in functions for concatenation, comparison, etc. (we rely on <cstring>).
  - Risk of buffer overflow.

C++ gives us a better alternative — the "string" class from <string> header.
This "string" is actually an **object** created using OOPs concepts.

To understand how string works, we need a basic intro to OOPs.


What is OOPs? (Object-Oriented Programming)
---------------------------------------------
OOPs is a programming paradigm based on the concept of "objects".

Key Concepts:
  1. Class    — A blueprint/template for creating objects.
  2. Object   — An instance of a class (a real entity created from the blueprint).


What is a Class?
-----------------
A class bundles together:
  - Data (properties/attributes)
  - Functions (methods/behaviors)

Think of it like:
  Class  = Design of a Car
  Object = An actual Car built from that design


Example:
--------
  class Student {
      // properties (data)
      string name;
      int age;
      float marks;

      // methods (functions)
      void printInfo() {
          cout << name << " " << age << " " << marks;
      }
  };

  // Creating an object
  Student s1;       // s1 is an object of class Student
  s1.name = "Aman";
  s1.age = 20;


How does this relate to Strings?
----------------------------------
The C++ "string" is a class defined in the <string> header.

When we write:
  string name = "Hello";

Here:
  - "string" is the class
  - "name" is the object
  - "Hello" is the value stored inside the object

Since "name" is an object, it comes with built-in methods (functions):
  name.length()      → returns the length of the string
  name.substr(1, 3)  → returns a substring
  name.find("llo")   → finds position of a substring
  name.erase(0, 2)   → erases characters
  name.append("!")    → appends to the string
  name.empty()        → checks if string is empty


String Declaration & Initialization
--------------------------------------
  #include <string>

  string s1;                 // empty string ""
  string s2 = "Hello";      // initialized with "Hello"
  string s3("World");       // another way to initialize
  string s4 = s2;           // copy of s2


Accessing Characters
---------------------
  string s = "Hello";
  s[0]  → 'H'
  s[1]  → 'e'
  s.at(4) → 'o'   (with bounds checking)


Input / Output
---------------
  string s;
  cin >> s;           // reads a single word (stops at space)
  getline(cin, s);    // reads the entire line (including spaces)
  cout << s;


Operators on Strings (Operator Overloading)
---------------------------------------------
Since string is a class, C++ allows operators to work on objects.
This concept is called **Operator Overloading**.

  string a = "Hello";
  string b = " World";

  string c = a + b;       // Concatenation → "Hello World"
  a += b;                 // Append → a becomes "Hello World"

  if (a == b) { }         // Comparison (checks equality)
  if (a < b)  { }         // Lexicographic comparison
  if (a != b) { }         // Not equal


The dot (.) Operator
---------------------
We use the dot operator to access methods/properties of an object.

  string s = "Hello";
  s.length();    // calling the length() method on object s
  s.clear();     // clears the string


Summary
--------
  - A Class is a blueprint with data + functions.
  - An Object is a real instance of that class.
  - C++ string is a class; every string variable is an object.
  - Objects have built-in methods accessed using the dot (.) operator.
  - Operators like +, ==, < work on strings due to operator overloading.
  - This is why we need a basic understanding of OOPs to use strings effectively.
