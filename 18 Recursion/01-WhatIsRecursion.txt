What is Recursion?

Recursion is a way of solving a problem where a function calls itself.

In simple words:
A big problem is broken into smaller problems of the same type.
The function keeps calling itself until a stopping condition is reached.

Two important parts of recursion:

1. Base Case
   - This is the stopping condition.
   - Without a base case, the function will call itself forever.

2. Recursive Case
   - This is where the function calls itself with a smaller input.
   - Each call should move toward the base case.

Example idea: Counting down from n to 1

If n = 5:
print 5, then call function for 4
print 4, then call function for 3
print 3, then call function for 2
print 2, then call function for 1
when n = 1, stop (base case)

Why use recursion?
- It can make code short and clean.
- It is useful in problems like factorial, Fibonacci, tree traversal, and backtracking.

Important note:
- Every recursive function can also be written using loops.
- Recursion is powerful, but use it carefully to avoid extra memory use.
